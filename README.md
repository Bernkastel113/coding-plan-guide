# Coding Plan 选择指南

一张表选清楚 50 档 AI Coding Plan：17 家厂商的价格、额度测算与模型基准横评。

- 纯静态站点：零依赖、零构建、零外部请求，clone 后直接用浏览器打开 `index.html`
- 数据快照：2026-09-25（价格与基准分数来自公开渠道整理，购买前请以各官网为准）
- 自检：`node verify.js`（数据完整性 + 结构断言；加 `--dom` 可跑渲染级断言，需本机装有 Edge）

## 目录结构

```
index.html            页面骨架
assets/css/style.css  样式（含设计令牌）
assets/js/app.js      渲染与交互
assets/data/data.js   全部数据（唯一数据源，改数据只动这个文件）
verify.js             自检脚本
```

## 数据口径

- 价格为官方渠道标价；海外套餐附人民币换算参考（汇率随快照记录在 data.js meta 中）
- 模型基准分数按评测分列展示，不同评测量纲不同、不可直接横比；带 † 为第三方复测口径
- 查不到可靠分数的格子留白（—），不编造数据；额度测算所用模型在套餐表内逐档标注

数据为不定期手动维护的快照，页面超过 7 天未更新会显示数据时效提醒。
